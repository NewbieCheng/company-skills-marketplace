# 目标路径结构

## 固定根路径

默认目标根路径：

```text
九江双蒸知识库v1.0/一、私域库/01_产品库/01.4_产品素材库
```

该 Skill 只向这个产品素材库复制素材。不要把用户案例主路径改到 `03_用户案例库`。

## 标准目录结构

二级目录先按文件类型划分：

```text
01.4_产品素材库/
├── 图片类素材/
├── 视频类素材/
├── 文档类素材/
├── 00_待人工确认/
└── 99_入库索引/
```

三级目录按产品或产品细分名划分：

```text
图片类素材/菠萝酒/
视频类素材/菠萝酒/
文档类素材/菠萝酒/
```

当原始素材已有更细产品目录，优先使用扁平产品名，例如 `青梅酒_福建青梅`，避免继续嵌套三四层。

## 图片类素材目录

图片类素材在产品目录下继续细分：

```text
图片类素材/
└── <产品名>/
    ├── 00_待人工确认/
    ├── 01_产品实拍/
    ├── 02_好评截图/
    ├── 03_用户晒单/
    └── 04_用户咨询/
```

## 视频类素材目录

视频类素材不做用户场景细分：

```text
视频类素材/
└── <产品名>/
    └── <原文件名>
```

## 文档类素材目录

PDF、Word、Excel、PPT 等全部归入文档类素材，不做用户场景细分：

```text
文档类素材/
└── <产品名>/
    └── <原文件名>
```

## 索引文件

每次正式复制后，在目标根路径下追加或创建同一套索引：

```text
99_入库索引/
├── 素材入库总表.md
├── 待人工确认清单.md
└── 异常清单.md
```

`素材入库总表.md` 是图片、视频、文档共同维护的唯一总表。不要为图片、视频、文档分别创建独立总表。

索引必须记录文件类型、产品、图片分类、原始来源、目标路径、置信度和备注，方便回查。

## 文件命名

默认保留原文件名。发生同名冲突时，在扩展名前追加短 hash：

```text
原名_ab12cd34.jpg
```

不要覆盖已有素材，不批量重命名已有素材。
