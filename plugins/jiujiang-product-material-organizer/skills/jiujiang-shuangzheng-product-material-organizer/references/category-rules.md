# 分类规则

## 第一层判断：文件类型

先判断文件类型，再判断产品。

| 文件类型目录 | 扩展名 |
|---|---|
| `图片类素材` | `.jpg`、`.jpeg`、`.png`、`.webp`、`.heic`、`.gif`、`.bmp`、`.tif`、`.tiff` |
| `视频类素材` | `.mp4`、`.mov`、`.m4v`、`.avi`、`.mkv`、`.webm`、`.wmv` |
| `文档类素材` | `.pdf`、`.doc`、`.docx`、`.xls`、`.xlsx`、`.csv`、`.ppt`、`.pptx`、`.pages`、`.numbers`、`.key`、`.txt`、`.md` |

无法判断文件类型时，放入根目录 `00_待人工确认`。

## 第二层判断：产品

产品通常来自人工标注、原始文件夹名或文件名。产品不明确时放入该文件类型下的 `00_产品待确认`。

不要为了让目录好看而新建未确认产品名。

## 第三层判断：图片分类

只有 `图片类素材` 继续判断图片分类：

| 目录 | 定义 |
|---|---|
| `00_待人工确认` | 产品不明、类型不明、画面模糊、文字不可读、同时像多类、路径和内容冲突 |
| `01_产品实拍` | 中性产品展示，包括瓶身、包装、原料、货架、泡制物、品牌陈列 |
| `02_好评截图` | 用户明确正向评价，包括好喝、满意、不错、推荐、复购倾向、夸品质 |
| `03_用户晒单` | 用户展示自己收到、泡制、饮用、摆放、开箱或分享的实物图 |
| `04_用户咨询` | 用户提问，包括价格、规格、泡法、适合人群、购买方式、送礼、保存 |

视频类素材和文档类素材不区分 `产品实拍 / 好评截图 / 用户晒单 / 用户咨询`。

## 图片判定优先级

```text
04_用户咨询 > 02_好评截图 > 03_用户晒单 > 01_产品实拍 > 00_待人工确认
```

优先级用于解决同一张图出现多个信号时的主分类。如果无法清楚判断哪个是主信号，放 `00_待人工确认`。

## 高置信判断

允许自动入库的最低条件：

- 文件类型明确；
- 产品归属明确；
- 图片类素材的图片分类主信号明确；
- 没有与原始目录或文件名的明显冲突；
- 置信度不低于 `0.90`。

低于 `0.90` 不自动入正式分类，进入待人工确认。

## 常见冲突处理

- 聊天截图里用户在问问题，即使来自群聊，也归 `04_用户咨询`。
- 聊天截图里主要是夸好、满意、推荐，即使来自私聊，也归 `02_好评截图`。
- 产品图出现在用户生活场景，且重点是用户展示自己拥有或使用，归 `03_用户晒单`。
- 只有产品、包装、原料、中性陈列，归 `01_产品实拍`。
- 同时有咨询和好评，且无法判断主语义，归 `00_待人工确认`。
- 看不清文字的聊天截图，归 `00_待人工确认`。
- 产品归属不确定，归对应运行报告的待确认清单，不硬塞进某个产品。
- 视频和文档即使内容里有好评或咨询，也只按文件类型和产品归档，不拆用户场景。

## 事实边界

分类只判断文件类型、产品归属和图片素材类型，不推断：

- 功效或疗效；
- 用户身份、年龄、职业、收入；
- 购买动机；
- 合规可发布性；
- 产品卖点是否成立。
