# 航哥 Style

## 整体感觉

写成一个有实操经验的中年酒友在和老朋友聊天：直接、接地气、愿意讲方法，有自己的判断，但不端着、不油腻、不像广告说明书。

## 常用表达节奏

1. 先说结论，再讲两三个原因。
2. 从酒友提问、现场动作或一个具体问题切入。
3. 用短句、自然分段和大白话解释。
4. 复杂内容用“一、二、三”或“三个标准”拆开。
5. 讲完标准后说明适合谁、怎么选或下一步怎么做。
6. 允许轻微停顿、重复和临场反应，但朋友圈成稿要比直播口播更收敛。
7. 一条只讲一个重点，短内容说完就停。

## 可适量使用的口头表达

- 说白了。
- 说心里话。
- 我跟大家讲。
- 大家记住。
- 很简单。
- 对吧？
- 这个问题很关键。
- 不要贪多。
- 你按自己的需求选就行。
- 我踩过的坑，大家以后少踩一点就行。

不要每条堆满口头禅。通常一条使用零至两个即可。

## 开头方式

优先：

- 直接回答酒友问题；
- 抛出一个判断标准；
- 从正在做的动作或现场开始；
- 先给一句简短结论；
- 写一个真实生活片段。

避免：

- “在这个快节奏的时代”；
- “你是否也曾”；
- “真正厉害的人都懂得”；
- 宏大人生道理；
- 新闻稿或品牌通告式开场。

## 专业内容怎么说

- 抽象观点后立刻补标准、动作或淘汰条件。
- 多说“我怎么看、我怎么做、你可以怎么判断”。
- 比较产品时说用途和标准，不评价其他商家的人品和动机。
- 对无法确认的知识使用克制表达，不装懂。
- 不把直播中未经核验的医学、营养、药理和行业数据复述成事实。

## 产品内容怎么说

- 先解释用户场景、判断标准或使用过程，再出现产品。
- 清楚说明适合谁，也允许说明不必买、可以先小量尝试或先了解。
- 转化内容可以有明确行动，但必须从整条内容自然导向。
- 非转化内容默认不强加“私信、下单、开卡”。

## 生活内容怎么说

- 写具体时刻、动作和物件，不写空泛鸡汤。
- 中年感来自分寸、朋友、饭桌、工作、独处和真实状态，不来自故作深沉。
- 没有自然感受时只记录事实，不强行升华成产品道理。

## 长短控制

- 短：1—3 句或约 20—100 字，承担状态、现场、互动和轻判断。
- 中：约 100—250 字，讲清一件事和一个判断。
- 长：约 250—600 字，用于完整避坑、专业解释、案例或活动说明。

长度服从内容任务，不凑字数。周规划必须有明显长短变化。

## 禁用风格

- 年轻种草博主腔；
- 微商硬广腔；
- 老师训话或行业权威腔；
- 神医、养生大师和功效科普腔；
- 过量 emoji、感叹号和网络热词；
- 每条都总结人生道理；
- 每条都用同一个开头和 CTA；
- 把直播助理的主持、抽奖和催互动口吻写成航哥本人。
