## 1. 总原则

不要靠“别人差、我们好”完成说服。采用：

```text
给出判断标准
→ 展示真实过程
→ 放入具体场景
→ 说明对酒友的帮助
→ 让用户自己判断是否适合
```

## 2. 所有内容的硬性红线

出现任一项时停止交付正文，改写或标记待确认：

- 编造航哥经历、客户、晒单、成交、反馈、库存、活动或产地证据；
- 把计划、历史样本或模型建议写成已经发生；
- 宣称治疗、调理、补肾、壮阳、改善疾病或确定身体功效；
- 根据体质、性别、症状、用药或疾病给出饮用建议；
- 给出未经正式资料确认的饮用量、饮用频率和适用人群；
- 用“药酒不是药”替前面的功效宣传免责；
- 暗示“别人造假”“只有我们是真的”但没有正式证据；
- 制造虚假果期、库存、截止时间和稀缺；
- 泄露客户、家人、订单、聊天或项目隐私；
- 鼓励未成年人、孕期人群、驾驶前后或不适宜饮酒人群饮酒。

## 3. 避坑内容

### 必须做到

- 从一个真实疑问或常见操作问题开始；
- 说明差异为什么会产生；
- 给用户可以执行或核实的判断方法；
- 自家产品只作为标准的一个执行例子；
- 删除品牌后，内容仍应对用户有用。

### 标准数量

- 短内容：至少 2 个明确标准；
- 中等内容：2—4 个标准；
- 完整指南：3—5 个标准。

标准可包括产地、品种、外观、香气、成熟度、处理状态、认证、包装标识、追溯信息和实际操作表现。只有真实资料支持时才能使用。

### 禁止结构

```text
市场很乱
→ 别人都不行
→ 只有我们专业
```

## 4. 专业背书

专业感来自标准和过程，不来自自我宣布。

中长内容优先形成：

```text
观点
→ 判断标准
→ 实际行动
→ 细节证据或淘汰条件
→ 对酒友的帮助
```

短内容至少完成一组有效连接：

- 一个判断 + 一个动作；
- 一个现场观察 + 一个选择理由；
- 一个淘汰条件 + 对结果的影响。

出现“专业、严格、精挑细选、高标准、高品质、好果子、层层把关”等词时，必须继续说明：

- 具体看什么；
- 具体做什么；
- 什么情况不用；
- 这个标准影响什么。

长期合作、熟人关系和果农信任只能作为辅助信息。正确顺序是：

```text
标准
→ 实际执行
→ 长期合作形成默契
```

## 5. 比较内容

- 只比较产地、品种、材料状态、工艺、用途、口感、预算和适用场景；
- 不评价其他商家的人品、动机和真假；
- 不用无法验证的市场比例；
- 不说“没有绝对好坏”后又暗示只有自家可选；
- 体验差异必须来自航哥真实体验、正式产品资料或经授权反馈；
- 主观体验写成个人感受，不写成所有人都会出现的结果。

## 6. 场景种草

场景元素包括：

- 时间；
- 地点；
- 具体物件；
- 人物动作；
- 感官体验；
- 情绪或关系。

按长度要求：

- 短内容：至少 2 个真实场景锚点；
- 中等内容：至少 3 个场景元素；
- 长场景种草：至少 4 个场景元素。

只使用真实发生或用户明确要求的可构造产品使用场景。不能把“天气热了”“节气到了”当成完整场景，也不能编造航哥当晚吃了什么、和谁喝酒。

卖点优先通过动作和体验呈现，少用“特别好喝、很舒服、最适合夏天”等自我评价。感官描写必须有真实体验来源。

## 7. 产品与行动转化

### 非转化内容

- 真人生活、知识和避坑内容默认无 CTA 或使用轻承接；
- 不在生活故事末尾突然加“需要的私聊”“赶快下单”。

### 明确转化内容

可以直接邀请咨询、开卡、下单、复购或参与活动，但必须：

- 从开头就明确服务于转化任务；
- 产品、价格、活动、权益和入口真实存在；
- 解释适合谁、为什么现在需要；
- 不制造虚假紧迫感；
- 承接动作真实可执行。

推荐承接：

- 提醒准备材料和容器；
- 邀请提供实际情况后再判断；
- 引导查看已经存在的教程或清单；
- 说明真实活动和服务入口；
- 提醒已购买用户的下一步操作。

不得假装已经自动打标签、自动私聊或自动跟进。

## 8. 长短适配

- 不为满足规则把短内容扩成长文；
- 短内容允许只记录一个现场或一个判断；
- 中等内容讲清一件事和一个轻量理由；
- 长内容才承担完整教程、证据链、案例或活动说明；
- 同一周避免所有内容长度、开头和结尾相同；
- 一条只承担一个主要经营目的。

## 9. 负向拦截

出现以下情况时标记“需重写”：

- 主要通过贬低市场或同行突出自己；
- 避坑内容没有判断方法；
- 私人关系被当作核心质量证据；
- 使用抽象专业词但没有标准、动作和淘汰条件；
- 场景只有季节和天气；
- 生活故事突然切换为硬销售；
- 先宣布“我们的最好”，再强行寻找理由；
- 所有结论都由品牌自我宣布，没有事实和过程；
- 短内容被写成压缩后的鸡汤长文；
- 同一周重复使用相同开头、观点、场景或 CTA。

出现事实、合规、隐私或活动冲突时，不只重写，标记“待补事实”或“待人工确认”。

## 10. 发布前检查

### 事实

- [ ] 时间、人物、行为、结果和情绪有来源；
- [ ] 计划没有写成完成；
- [ ] 产品、价格、库存、活动和权益来自最新正式资料；
- [ ] 客户、晒单和成交真实且可公开；
- [ ] 没有把样本事实复用到当前内容。

### 价值与专业

- [ ] 一条只承担一个主要任务；
- [ ] 避坑内容给出可执行标准；
- [ ] 抽象专业词后有具体证据；
- [ ] 私人关系只是辅助信息；
- [ ] 删除品牌后，知识型内容仍有价值。

### 场景与表达

- [ ] 场景达到对应长度的具象要求；
- [ ] 像航哥，不像助理、广告稿或 AI 模板；
- [ ] 长短、开头、节奏和 CTA 有变化；
- [ ] 没有强行鸡汤和功效暗示；
- [ ] 转化与内容目的匹配。

### 发布状态

- `可发布`：事实、表达、隐私和最低合规检查通过；
- `需重写`：事实可用，但表达规则未通过；
- `待补事实`：缺少支撑正式正文的关键事实；
- `待人工确认`：存在价格、活动、隐私、授权、健康或资料冲突。
