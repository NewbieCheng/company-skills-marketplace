# 九江双蒸用户假设报告模板 2.0

## 使用规则

- 从 YAML 元数据开始生成完整 Markdown 预览。
- `report_schema_version` 固定为 `2.0`；`version` 是单个产品报告的业务版本。
- 用已知内容替换方括号；无法确认时写 `unknown`，不要编造。
- 第一层只服务人类决策，第二层负责证据追溯，第三层只服务下游 AI。
- 保留第三层的 YAML 字段和含义；无内容时保留空值或空数组。
- 三层共享同一组 `E/H/J/T` 编号，不在不同层重新创造结论。

## 模板开始

---

evidence_level: 低/中/高
