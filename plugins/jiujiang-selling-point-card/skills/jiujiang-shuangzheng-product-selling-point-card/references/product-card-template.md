# 九江双蒸产品卖点分析报告模板 v2.1

## 使用规则

- 输出一个 Markdown 文件，顺序固定为：小白使用说明 → 八个人类决策问题 → 证据与判断附录 → AI 交接区。
- 前六问负责当前卖点判断；第七问负责证据补充；第八问负责执行复盘和下一版本。
- 每个问题先给直接答案，再给最少必要依据，最后写限制或下一步。
- 对人类使用易懂标识；规范状态只在证据附录和 AI 交接区集中呈现。
- 声明使用唯一 ID `C001`、`C002`……；证据缺口使用唯一 ID `G001`、`G002`……。
- 只有 `confirmed + existing + direct` 可列入“现在可以直接说”和 `direct_claim_ids`。
- FAQ 的可确认回答不得承诺待补证明、计划能力和未交付教程。
- SKU 标称与已确认属性分开，不因名称包含产地、年份或工艺而确认其真实性。
- 旧版发现结果为 `none` 时首次报告使用 `version: v1`；选中旧版时按其版本递增，没有可用版本的旧报告视为基线 `v1`，新报告从 `v2` 开始。`template_version: "2.1"` 只表示报告结构版本。
- `previous_report` 只填写自动发现后唯一选中的最新旧版；未选中的其他旧报告不得作为来源或进入上下文。

## 人类阅读标识

- ✅ 已确认、当前存在、可按限制使用；
- 🟡 有依据但仍需验证；
- 🔵 已规划但当前还没有；
- ⚪ 信息未知；
- 🔴 存在冲突、风险或禁止使用。
